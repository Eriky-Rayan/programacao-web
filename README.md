## 🚀 Como Executar o Projeto

---

### 📋 Passo a Passo (Receitas 1 ~ 8)

1. **Acesse o menu (`main`) dando dois cliques (ou abrindo no navegador)**

2. **Escolha a receita desejada e clique no link**

---

### 📋 Passo a Passo (Menu Unificado Next.js — Receitas 13 ~ 21)

1. **Entre dentro da pasta `menu-nextjs`:**
   ```bash
   cd menu-nextjs
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse `http://localhost:3000` no navegador para visualizar a tabela do menu e navegar pelas rotas `/receita13` até `/receita21`.**

---

### 📋 Passo a Passo Individual (Receitas >= 9)

1. **Entre dentro da pasta `..._example` da receita desejada**

2. **Utilize o comando `"npm install"`**

3. **Utilize o comando `"npm run dev"`**

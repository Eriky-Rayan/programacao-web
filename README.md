# programacao-web
Repositorio destinado à materia de Programação Web (DCT1109) ministrada pelo professor Fabricio Vale de Azevedo Guerra.

## 🚀 Como Executar o Projeto

> **Atenção:** Cada receita está organizada em sua própria **branch**. Certifique-se de alternar para a branch correspondente à receita que deseja executar.

---

### 📋 Passo a Passo

1. **Alterne para a branch desejada**
```bash
git checkout <nome-da-branch>

```


2. **Navegue até a pasta da receita**
Substitua `N` pelo número da receita desejada:
```bash
cd receitaN

```


3. **Instale as dependências**
```bash
npm install

```
